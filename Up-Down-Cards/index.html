Custom deck

Prepare a deck that works

Follow these three steps, then upload your JSON file. We’ll check the structure before adding it to your library.

1

Use one object

Your file needs _title, _blur, and a non-empty cards list.

2

Keep fields consistent

Every card must contain the field named by _title. Use the same field names throughout.

3

Choose what to hide

Put answer fields in _blur. These are revealed when you swipe down.

A compliant vocabulary deck template.json 
{
  "_title": "word",
  "_blur": ["meaning", "sentence"],
  "cards": [
    {
      "word": "abandon",
      "phonetic": "/əˈbændən/",
      "meaning": "放弃",
      "sentence": "Never abandon your dreams."
    }
  ]
}

Before you upload

  • Saved as a .json file
  • cards contains at least one card
  • _title exists on every card
  • Every name in _blur is a card field
