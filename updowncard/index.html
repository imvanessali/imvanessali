Why I built this?

"Why not learn authentic English expressions while mastering top-tier product thinking at the same time?" That is why I built this website.

Swipe up if you know a card; tap or swipe down to reveal the answer — revealing marks it for review. It's like flashcards, but more TikTok-y.

Built by @imvanessali

JSON Format Guide

Upload a .json file to create your own flashcard deck. Your file should follow this structure:

{
  "cards": [
    {
      "word": "abandon",
      "phonetic": "/əˈbændən/",
      "meaning": "放弃",
      "sentence": "Never abandon your dreams."
    }
  ]
}

Rules

cards

Required. A non-empty array of card objects. Each card can have any fields you want (string or number values) — they are rendered automatically.

_title

Optional. Which field is the card heading. Defaults to the first field.

_blur

Optional. Array of field names to blur-hide initially. Both this and _title are just defaults — you can change field visibility anytime in the study view via Fields.

Tip: use to generate this JSON from any material.

Make a deck with AI

  1. Copy the prompt below.
  2. Paste it into your own AI (ChatGPT, Claude, Kimi, anything) together with your material — notes, articles, transcripts, any format.
  3. Save the AI's JSON output as a .json file and upload it here.

          

          
          
The prompt asks the AI to output only JSON in our format. If your file fails validation on upload, we'll tell you exactly what's wrong — paste the error back to the AI to fix it.
